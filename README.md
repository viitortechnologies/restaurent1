# JoyFul Restaurant Website

A modern, responsive website for JoyFul, an authentic Indian restaurant located in Hyderabad, Telangana.

## Features

- **Responsive Design**: Fully responsive layout that works on all devices
- **Modern UI**: Clean, modern design with smooth animations
- **Interactive Menu**: Filterable menu categories with beautiful food images
- **Contact Form**: Functional reservation form with validation
- **Image Gallery**: Clickable gallery with modal view
- **Smooth Scrolling**: Smooth navigation between sections
- **Mobile Navigation**: Hamburger menu for mobile devices

## Sections

1. **Hero Section**: Eye-catching landing area with call-to-action buttons
2. **About Section**: Restaurant story and features
3. **Menu Section**: Interactive menu with categories (Starters, Main Course, Breads, Desserts, Beverages)
4. **Gallery Section**: Photo gallery of the restaurant and food
5. **Contact Section**: Contact information and reservation form
6. **Footer**: Additional links and social media

## Technologies Used

- **HTML5**: Semantic markup
- **CSS3**: Modern styling with Flexbox and Grid
- **JavaScript**: Interactive functionality
- **Font Awesome**: Icons
- **Google Fonts**: Typography (Poppins & Playfair Display)

## Setup Instructions

1. **Clone or Download**: Download all files to your local machine
2. **Open in Browser**: Simply open `index.html` in any modern web browser
3. **No Server Required**: This is a static website that runs entirely in the browser

## Customization

### Replacing Images
The website currently uses sample images from Unsplash. To replace them:

1. **Hero Image**: Update the `src` attribute in the hero section
2. **Menu Images**: Replace the `src` attributes in menu items
3. **Gallery Images**: Update the `src` attributes in the gallery section
4. **About Image**: Replace the image in the about section

### Updating Content
- **Restaurant Name**: Update "JoyFul" throughout the HTML
- **Contact Information**: Update address, phone, and email in the contact section
- **Menu Items**: Modify menu items, descriptions, and prices
- **About Text**: Update the restaurant story and features

### Styling Changes
- **Colors**: Modify the CSS variables in `styles.css`
- **Fonts**: Change Google Fonts imports in the HTML head
- **Layout**: Adjust grid and flexbox properties in CSS
